# Definition of Done

A feature is considered complete only when all criteria below are satisfied.

## Functional

- Meets PRD and FRS requirements.
- Acceptance criteria pass.
- Edge cases handled.

## Code Quality

- Follows Coding Standards.
- No lint or TypeScript errors.
- No duplicated logic.

## Testing

- Unit tests added where appropriate.
- Existing tests pass.
- Critical user flows verified.

## UI/UX

- Matches Design System.
- Responsive on mobile, tablet and desktop.
- Loading, empty and error states implemented.
- Accessibility verified.

## Security

- Authorization enforced.
- Inputs validated.
- Sensitive data protected.

## Documentation

- Relevant documentation updated.
- New reusable components documented.

## Review

- Pull request approved.
- Ready for deployment.

Only after every item above is complete may a task be moved to **Done** on the HIVE Board.
