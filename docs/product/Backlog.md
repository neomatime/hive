# HIVE Product Backlog

## Guiding Principle

Only add features that improve project delivery.

---

# High Priority

## Projects
- Project archive restore
- Favourite projects
- Project duplication
- Bulk project actions

## Board
- WIP limits
- Swimlanes
- Saved filters
- Bulk task movement

## Tasks
- Subtasks
- Recurring tasks
- Dependencies
- Checklists
- Rich text comments
- Task watchers

## Calendar
- Drag to reschedule
- Recurring events
- Personal availability

## Files
- Version history
- Preview improvements
- Folder permissions

---

# Medium Priority

- Advanced search
- Keyboard shortcuts
- Global command palette
- Custom task labels
- Dark mode
- Dashboard widgets
- Export to CSV
- Printable project summary

---

# Low Priority

- Slack / Teams notifications
- Outlook calendar sync
- Google Calendar sync
- Public share links
- Offline mode

---

# Icebox

These ideas require future validation.

- AI meeting summaries
- AI task suggestions
- Voice task creation
- OCR for uploaded documents
- Mobile applications
- Whiteboard collaboration
- Custom automation rules
- External guest users

---

# Never Build

The following are intentionally excluded unless HIVE's vision changes.

- Billing
- Invoicing
- Payments
- CRM
- Sales pipeline
- Marketing automation
- Accounting
- ERP functionality

HIVE remains a focused internal project management platform.
