# HIVE MVP Roadmap

## Purpose

This roadmap defines the minimum feature set required to launch HIVE for internal use at HIMARK.

---

# Release Goal

Deliver a fast, reliable internal project management platform for planning, executing and tracking work.

---

# Phase 1 — Foundation

## Authentication
- Login
- Logout
- Password reset
- Session persistence

## Workspace
- Workspace settings
- User profile
- Role-based access

**Milestone:** Team can securely access HIVE.

---

# Phase 2 — Core Delivery

## Projects
- Create, edit, archive projects
- Search and filters
- Project members

## Board
- Kanban board
- Drag & drop
- Task creation
- Status updates

## Tasks
- Assignments
- Priorities
- Due dates
- Comments
- Labels

**Milestone:** Teams can manage project execution.

---

# Phase 3 — Collaboration

## My Tasks
- Personal task list
- Due today
- Overdue
- Completed

## Calendar
- Month / Week / Day views
- Deadlines
- Milestones

## Files
- Upload
- Download
- Organise by project

**Milestone:** Teams can collaborate around projects.

---

# Phase 4 — Administration

## Settings
- Profile
- Account
- Workspace
- Team
- Notifications
- Task Preferences
- Project Templates
- Integrations

## Activity
- Immutable activity feed

**Milestone:** HIVE is operational for daily use.

---

# Out of Scope (Post-MVP)

- Billing
- CRM
- Financial reporting
- AI assistants
- Time tracking
- Gantt charts
- Client portal
- External collaboration
- Mobile app
- Advanced reporting

---

# MVP Success Criteria

- Team can manage projects end-to-end.
- Board is the primary execution interface.
- Files, tasks and deadlines are connected.
- HIVE replaces ad-hoc spreadsheets for delivery.
